# Cybersecurity Log Analyzer

## About

Cybersecurity Log Analyzer is a beginner-friendly Python project that reads sample security logs and analyzes login activity.

## Features

- Counts total log entries
- Counts successful login attempts
- Counts failed login attempts
- Groups failed login attempts by user
- Detects repeated failed login attempts
- Displays a security analysis summary

## Technologies Used

- Python
- File Handling
- Lists
- Dictionaries
- Loops
- Conditional Statements
- Git & GitHub

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Make sure the terminal is inside the project folder.
4. Run:

```bash
python log_analyzer.py
